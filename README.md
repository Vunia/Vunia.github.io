# Claude Dock

A one-page site about **Claude Dock**, my Windows dock and voice companion for Claude Code.

Live: https://vunia.github.io

Plain HTML, CSS and JavaScript, no build step. Capri's animations are her sprite strips drawn on `<canvas>`.
