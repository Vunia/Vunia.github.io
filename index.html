How it works
  • Speech-to-text runs on the CPU (NVIDIA Parakeet via sherpa-onnx). No audio leaves the PC.
  • Words are typed into the terminal's input directly, so focus stays where you are.
  • Nothing is typed while Claude is asking for permission, so a stray word can't pick an option.

How it works
  • Claude Code's hooks tell the dock about each moment. A failed tool or a memory compaction gets a silent glitch.
  • For a finished reply she drops code, links and markdown and keeps the first sentence. That's the real rule from the dock, running here.
  • Her voice is Kokoro text-to-speech, on the CPU. If you're already looking at that chat, she only shows a caption.

    Under the hood
    • C# 5 and WPF, compiled by the C# compiler that ships with Windows (.NET Framework 4.8).
    • Claude Code runs ClaudeDock.exe --hook for its events; the dock reads Claude's own transcripts for chats, context and plan usage.
    • sherpa-onnx runs Parakeet (ears) and Kokoro (voice). Her effects are drawn in layered, click-through windows.
