Claude Dock

A dock on the edge of my Windows screen that runs Claude Code for me. I talk, it types. Claude finishes, Capri tells me. My chats, usage and voice controls sit one click away.

Meet her ↓ How I built it

  • 100% local voice

01

Talk to Claude from anywhere

Hold Ctrl Alt Space and speak. Capri listens, turns it into text on my own CPU, and types it straight into the Claude Code chat I'm in. If no chat is open, she opens one.

Hold the button (or Ctrl+Alt+Space) for a second, then let go.

This is a simulation. The real dock records your mic.

  • Runs on my PC. NVIDIA's Parakeet speech model, run by sherpa-onnx on the CPU. The text is back about a second after I stop talking. No audio leaves the machine.
  • Types without grabbing focus. Words go into the terminal's input directly, so I can keep working in another window.
  • Never answers for me. While Claude shows a permission prompt or a question, nothing gets typed, so a stray word can't pick an option.
02

She tells me when Claude is done

Claude Code's hooks tell the dock about the moments that matter. Capri says them out loud, so I can look away while Claude works. When it finishes, she reads the first sentence of its answer with the markdown, code and links taken out.

What Capri says

  • Only what matters. Finished, needs permission, has a question, hit an error. A failed tool or a memory compaction gets a silent glitch instead of words.
  • Quiet when I'm watching. If that chat's terminal is already in front, she shows a caption and doesn't speak.
  • Her own voice, offline. Kokoro text-to-speech on the CPU, lip-synced to her mouth. The model unloads after a minute of silence.

    04

    And she has a life of her own

    Small things that make the dock feel alive, all driven by what Claude Code and my PC are actually doing.

    Helper clones

    When Claude Code starts subagents, a small clone of her steps in for each one and leaves when it's done.

    She dances to my music

    She reads Windows' audio meters (nothing is recorded), finds the beat between 60 and 180 BPM, and sways on her window in time.

    Style her

    Hair and accent colours, a pixel-art look and outlines. The dock can match its accent to her. This slider recolours every Capri on the page.

    She lives on my desktop

    She sits on window tops and the taskbar, falls when a window closes, and teleports with a ribbon trail. She stays out of the way of fullscreen games and videos.

    05

    How I built it

    I built the whole thing with Claude Code in a terminal. I described what I wanted, tested it on my own desktop, and kept going until it felt right. This site was made the same way.

    ~8,900lines of C# 5 and XAML
    0installs: built by the C# compiler that ships with Windows
    2local AI models: one to listen, one to speak
    9Claude Code hook events the dock reacts to
    C# 5 / .NET Framework 4.8WPFWin32 console + layered windowsGDI+sherpa-onnxParakeet TDTKokoro TTSWindows audio metersClaude Code hooks
    • Hooks into Claude Code. The dock adds itself to Claude Code's hooks in settings.json and leaves the rest of that file untouched. Claude Code runs ClaudeDock.exe --hook, which passes the event to the running dock and exits.
    • Reads Claude Code's own files. It reads the session transcripts to find the chat I'm in, its title, how full its context window is, and my plan limits.
    • Smooth at any scale. Her animation follows the screen's refresh rate, frames are prepared in the background at her exact size, and she stays the same size on monitors with different scaling.
